# E-Commerce Sales & Probability Analysis

## Project Overview
This project analyzes e-commerce sales data using Python. It includes data cleaning, exploratory data analysis (EDA), probability analysis, and data visualization to identify sales trends and customer behavior.

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib


## Project Features
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Sales Trend Analysis
- Category-wise Sales Analysis
- Probability Analysis
- Customer Behavior Analysis
- Data Visualization

## Dataset
- 10,000+ E-commerce sales records
- CSV format
